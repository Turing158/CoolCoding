# 雨夜便利店 · 街角（三渲二微缩场景）

一个纯观赏用的 Three.js 三渲二（卡通渲染）微缩场景：雨夜中的日式便利店街角，
像一座可以自由拖拽、旋转、缩放观看的收藏级小模型。无任何 UI 界面元素。

## 运行

需要通过 HTTP 访问（ES Module 限制），任选其一：

```bash
# 方式一：自带零依赖服务器（推荐）
node server.mjs 8123

# 方式二：其它静态服务器
npx serve .
python -m http.server 8123
```

然后浏览器打开 <http://127.0.0.1:8123/>

## 操作

- 左键拖拽：旋转视角
- 滚轮：缩放
- 右键拖拽：平移（有范围限制，不会弄丢模型）

## 性能（CPU 友好）

- **默认帧率上限 30 FPS**（`main.js` 中的 `FPS` 常量），远低于满帧渲染的占用
- 窗口被遮挡/最小化时自动降频到约 10 FPS
- URL 参数可调：`?fps=24`（更省）/ `?fps=60`（更流畅）
- 像素比上限 1.5，全部动效由着色器时间驱动（降雨、涟漪、水痕零 CPU 更新）

## 测试专用参数（不影响正常访问）

- `?still=1`：完全停掉渲染循环（CPU 趋近零），通过控制台调用
  `__step(dt)` 单帧步进、`__state()` 查看动效状态机
- `?test=1`：提供 `__shot()`（同步渲染并读回画面）、`__cam(...)`（切机位）、
  `__pick(x,z)`（射线拾取）、`__toggleLight(i)`（灯光开关）等自动化测试钩子

## 场景内容

- **底座**：22×22 正方形收藏底座，所有元素紧凑布局其上
- **便利店**：发光招牌（偶发闪烁）、大面积玻璃橱窗、自动门（周期开合）、
  屋檐雨棚（檐口滴水）、门口地垫、营业时间牌
- **店内**（透过橱窗可见）：货架商品、饮料柜、便当柜、饭团柜、收银台、
  咖啡机、关东煮柜台（冒热气）、炸物柜、杂志架、冰淇淋柜、ATM、海报灯箱、后场门
- **街角**：L 形道路交叉口、反光斑马线、停止线、排水沟+雨水箅、井盖、
  护栏、停车位（划线+P 牌）、小巷入口、邻楼（霓虹招牌+点亮窗户+水箱）、公告栏、空调外机
- **街道设施**：电线杆+垂弧电线、路灯（光锥+光池）、交通信号灯（轮换）、
  凸面镜、路牌、自动贩卖机（微脉动）、自行车、雨伞架、垃圾桶、猫
- **雨夜动效**：持续降雨（着色器驱动）、积水面涟漪、玻璃雨水滑落、
  檐口滴水+水花、招牌/霓虹偶发闪烁、积水反射灯光（路口积水颜色跟随信号灯）

## 技术要点

- Three.js r160（本地 `libs/`，离线可用），`MeshToonMaterial` 三阶渐变 + 反转法线外壳描边
- 重视觉：暖色店内光 vs 冷色雨夜街景、湿润路面 Phong 高光、加性光晕/光池
- 商品使用 InstancedMesh（约 900 实例），静态几何共享缓存
