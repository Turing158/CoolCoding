# 层间 · STACKED

一盒小城，四层日常。用 **Three.js r160** 搭建的多层乐高风格沙盘，玻璃展示外壳里收纳车库、街区、电车公园和屋顶花园。所有几何体、标牌贴图和花粉都由代码生成，运行时不请求 CDN、外部图片或字体。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

打开 <http://127.0.0.1:8130/>。请使用 HTTP 服务，不要直接双击 `index.html`。

```sh
npm run build       # 输出到 dist/
npm run preview     # 在 8130 端口预览构建；先停止开发服务
npm run check:motion
```

构建使用相对资源路径，可将 `dist/` 部署在静态网站的根目录或子目录。Three.js 严格锁定为 `0.160.0`，打包后可在无外网的局域网环境中使用。

## 四层小世界

| 楼层 | 主题 | 可以发现的细节 |
| --- | --- | --- |
| 01 | 车库进行时 | 红色小车、双工位维修车库、工具墙、抽屉、备胎、维修员与绿植 |
| 02 | 转角好天气 | 三栋拼砖街屋、门窗、烟囱、窗台花箱、咖啡雨棚、邮筒和黄色巴士 |
| 03 | 电车慢时光 | 橙色电车、双轨和枕木、受电弓、候车亭、长椅、乘客与树木 |
| 04 | 云上花园 | 三辆不同颜色的车辆、行李箱、树木、花坛、野餐桌、遮阳伞和散步的人们 |

模型共约 **6,721 个实例部件、24 个角色／车辆、11 个移动实体**。选择左侧楼层即可进入有独立透明外壳的单层近景，选择“完整小世界”恢复四层展示。

| 左键拖动 | 围绕当前目标旋转 |
| 右键拖动 | 在相机平面内平移，查看细节 |

## 性能与运动约束

- 默认目标 60 FPS；平衡预设限制像素比至 1.35、阴影贴图为 1024。实际帧率取决于设备与 WebGL 实现，可切到 24／30 FPS 或节能预设。系统要求减少动态效果时，默认暂停并关闭花粉。
- 静态积木和运动模型按几何类型、细节档位批量实例化；人物四肢和车轮复用固定实例槽位，不在动画中创建网格。
- 阴影只在首次绘制或场景设置变化时更新；运动实体使用轻量接触阴影。无后处理、实时反射或玻璃透射额外渲染通道。
- 用定时器按帧率唤醒 `requestAnimationFrame`，页面隐藏时停止调度。暂停且没有自动环视或视角过渡时，停止连续渲染；操作控件与拖动才按需重绘。
- 花粉采用两个固定容量为 36 的对象池，原地回收，复用位置、寿命与速度数组；粒子位置被约束在对应楼层内。
- 行人、车辆使用闭合圆角路径；每步检查完整旋转包围盒与边界、建筑、家具和其他实体的分离轴碰撞。积分步长不超过 1/40 秒，避免低帧率或提速后穿越障碍；空间不足时等待让行。
- 面板的毫秒数是 CPU 更新与绘制提交耗时，不是完整 GPU 帧时间，不能据此推断已达到 60 FPS。

## 低负载实测

```text
http://127.0.0.1:8130/?test=1&fps=6&frames=12
http://127.0.0.1:8130/?still=1&fps=6
```

`test=1` 默认以 6 FPS 运行，自动渲染 12 帧后暂停；测试帧率最高 12 FPS，帧数限制为 1–120。暂停后，用户操作仍可按需触发额外帧。“继续时光”会再运行一个有界的 12 帧周期。`still=1` 从静止画面开始，适合截图与布局检查。测试模式显式运行这一小段动画，不受系统“减少动态效果”的初始暂停影响。

页面内提供 `window.__STACKED__.snapshot()`、`audit()`、`advance(seconds)` 和 `renderOnce()` 调试接口。`advance` 每次最多推进 60 秒物理模拟，不启动渲染循环；只读诊断也保存在 `#scene-diagnostics` 的 JSON 文本里。

`npm run check:motion` 在 Node 中检查真实场景布局，对 11 条移动路径采样 17,600 个位置，再模拟约 617 秒，检查碰撞、边界和各角色能否完成多圈路线，同时验证花粉池复用数组。该检查不创建 WebGL 上下文。

已使用 Codex 内置浏览器以有限帧数完成加载、楼层近景、旋转、缩放、面板和响应式检查。低帧率实测用于验证功能与调度，不代表做过持续 60 FPS 压测。

## 文件

- `src/kit.js`：积木实例化、共享几何体、程序化标牌。
- `src/models.js`：车辆、乐高小人、植物与家具。
- `src/scene.js`：四层场景、透明外壳与细节管理。
- `src/motion.js`：路径、碰撞约束与花粉对象池。
- `src/main.js`：渲染、节流、相机、交互与诊断。
- `src/ui.js`、`src/style.css`、`src/ui.css`：界面与响应式布局。
- `PROMPT.md`：本场景原始任务提示词。
