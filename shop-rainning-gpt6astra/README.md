# 雨宿り · AMAYORI

一座没有人物、带可收起设置条的日式雨夜便利店微缩景观。使用 Three.js 构建真实三维几何，全部贴图均在本地以 Canvas 绘制，无外部素材或字体请求。

## 运行

```sh
npm install
npm run dev
```

打开终端中的本地地址。生产构建使用 `npm run build`，构建预览使用 `npm run preview`。

## 观看

- 左键拖拽 / 单指拖动：旋转。
- 滚轮 / 双指捏合：缩放。
- 右键拖拽 / 双指拖动：平移。
- 双击或 Home：恢复初始视角。
- 聚焦场景后，方向键旋转，加减键缩放。

## 场景设置

底部设置条可以收起；展开时自动为模型留出观看空间。

- **画质预设**：节能、平衡、精细；单独更改参数后显示为自定义。
- **帧率上限**：6 / 12 / 24 / 30 / 45 / 60 FPS，即时影响实际渲染调度。
- **渲染精度**：65% / 100% / 135%，调整画布内部渲染分辨率。
- **阴影质量**：关闭 / 512 / 1536 / 2048，切换时释放旧阴影贴图并重新生成。
- **积水反射**：关闭、节能、标准、精细，分别调整反射分辨率与刷新频率。
- **雨量**：0–100%；设为 0 时停止绘制雨线、滴水、波纹和玻璃水痕。
- **更多参数**：调整画面亮度、灯光辉光；辉光设为 0 时跳过对应后处理。
- **播放 / 暂停动效、视角复位、恢复默认**：暂停时仍可旋转、缩放和调整画质。

画质设置保存在当前浏览器中，刷新后恢复。测试模式使用独立的设置存储，不覆盖正常观看的偏好。视角与暂停状态不持久化。

## 场景

完整正方形底座、L 形街角、双面玻璃便利店、日文灯箱、四组货架、三组饮料冷柜、408 件商品、饭团与便当、收银台、咖啡机、关东煮、杂志架、冰柜、后场门、店内海报与地面导视。

室外包含两台自动贩卖机、自行车、雨伞架、分类垃圾桶、路灯、电线杆与悬垂电线、路牌、信号灯、护栏、停车位、斑马线、盲道、排水沟、井盖、小巷、空调外机、屋顶设备与公告栏。

环境动画包含持续降雨、屋檐滴水、玻璃水痕、积水波纹、打散的实时倒影、招牌细微亮度变化、周期性自动门和交通灯变化。

## 性能与有限帧数实测

- 默认 **24 FPS**，用户可调整至最高 60 FPS；使用定时器调度实际渲染，避免空转的高频循环。
- 页面隐藏后暂停；系统启用“减少动态效果”时默认降至 12 FPS，减少雨量、减慢环境动画并关闭招牌闪烁。
- 阴影只在初始化、切换阴影质量及显卡上下文恢复时更新。
- 静态模型按材质合并，雨线与波纹使用 GPU 动画。
- 标准反射长边为 768 像素，每 240 毫秒更新；节能档为 384 像素 / 500 毫秒，精细档为 1024 像素 / 125 毫秒。
- 标准渲染约限制在 185 万像素以内，精细档最高 340 万像素；测试模式保持 115 万像素上限。

低负载测试地址：

```text
http://127.0.0.1:5173/?test=1&fps=6&frames=12&motion=1
```

此地址初始使用 6 FPS，只运行 12 帧环境动画，随后停止。鼠标、键盘和设置操作仍会按需绘制；调整参数不会自动恢复播放。点击“播放动效”可以再运行一轮 12 帧。`motion=1` 仅在测试模式覆盖系统减少动态效果的偏好，以便检查动画；不会变更系统设置。可以添加 `time=9` 查看自动门打开阶段，添加 `time=13` 查看关闭阶段。

测试模式在 `#world` 的 `data-diagnostics` 属性输出只读状态，包含帧数、暂停状态、帧率上限、实际帧间隔、反射更新次数、相机、自动门位置及错误列表；这些信息不会显示在画面中。
