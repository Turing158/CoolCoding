# 验收记录

2026-09-17 完成续接验收。测试对象为当前源码经 `npm run build` 生成的生产构建，通过 `npm run preview` 在 `http://127.0.0.1:8132/` 提供服务。

## 环境与负载限制

- Windows，本机 Node.js 24.18.0、npm 12.0.2、Vite 6.4.1、Three.js r160。
- 使用 **Codex 内置浏览器**，没有另启 Chrome 或无界面 WebGL 压测。
- 交互验收使用 `?test=1&fps=6&frames=12`：最多 6 FPS，初始绘制 12 帧后停止；完整动画通过按钮追加有限帧数。
- 正常观看模式与成品截图使用 `?still=1&fps=6`，自动环绕关闭。动画结束后按需渲染器停止绘制。
- 桌面 1440 × 900、手机 390 × 844、平板 768 × 1024；尺寸由浏览器视口覆盖测试，设备像素比为 1。

## 验证边界

本轮验证功能、画面和停止绘制行为，没有执行持续 30／60 FPS 压测，也没有测量 CPU 占用率、GPU 帧时间、功耗或显存峰值。诊断中的 `frameCpuMilliseconds` 仅表示 JavaScript 提交一帧的耗时。

手机和平板采用桌面浏览器的视口模拟，未使用真实触屏设备；未覆盖其他浏览器、全部显卡、主动 WebGL 上下文丢失恢复、系统减少动态效果设置，以及后台标签页暂停／恢复。右键平移和全部键盘快捷键未在本轮逐一复测。上述能力不能由现有截图推断为跨设备验收通过。

模型为艺术性程序化重现，未进行测绘精度或历史构件尺寸核验。
