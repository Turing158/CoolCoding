# 云鲸渡 · WHALEHAVEN

一座在鲸背上穿过暮色云海的原创小镇。最终运行文件只有 **`index.html`**：内嵌 Three.js r160，无 CDN、外部模型、图片、字体或网络请求，双击即可离线打开。

## 观看

- 双击 `index.html`，使用支持 WebGL 的现代浏览器打开。
- 左键拖动旋转，滚轮缩放，右键或 Shift + 拖动平移；触屏支持拖动和双指缩放、平移。
- 三种视角：远航全景、鲸背小镇、与鲸同行。
- 空格暂停 / 继续；`R` 回到全景；`H` 隐藏 / 显示界面。画布获得焦点后，方向键旋转，`+` / `-` 缩放。
- 天光滑杆连续切换日间、暮色与夜晚；相机按钮保存不含界面的 PNG。
- 默认上限 24 FPS；节能模式上限 12 FPS。暂停后按需绘制；页面隐藏后取消调度。系统开启“减少动态效果”时从静止画面开始。

## 低负载实测

可用任意静态 HTTP 服务器，或直接给本地文件 URL 添加以下参数：

```text
index.html?test=1&fps=6&frames=12
index.html?still=1
index.html?test=1&still=1&t=21
```

`test=1` 默认以 6 FPS 绘制至多 12 个动画帧后自动暂停；暂停后的相机操作只按需重绘。点击“继续航行”启动下一批有限帧。系统减少动态效果优先，需主动点击继续才开始这批动画。`t` 指定初始动画时间，便于单帧检查呼气、尾部和云层的不同状态。`fps` 限制到 1–30，`frames` 限制到 1–120。

运行状态保存在隐藏的 `#diagnostics` 输出中，亦可在开发者控制台读取 `window.__whale.getState()`。测试模式另作 720 次无渲染采样，检查行人在木栈桥边界以内以及相互间距。详细浏览器验收见 `VALIDATION.md`。

## 场景与实现

- **鲸鱼**：连续截面曲面、深色背部与浅色腹部、程序化斑驳皮肤 / 凹凸纹理、双眼与高光、嘴线、23 道腹褶、头部结节与藤壶、双呼吸孔、长胸鳍、背鳍、尾柄及分叉尾鳍。
- **小镇**：22 栋街屋、铜绿天文台、钟楼、风车、花箱、市场雨棚、树木、前端凉亭、悬挑栈桥、垂吊花园、街灯、灯串、码头和系留热气球；13 位居民沿桥上双向闭合路线漫步。2,069 个静态构件按材质合并。
- **运动**：鲸身缓慢升沉与俯仰、尾柄连续弯曲、尾鳍延迟摆动、胸鳍配平；城镇随鲸保持刚性连接。云气绕开鲸身并在尾后扩散，周期性呼气有向上初速度、扩散和顺风漂移；烟雾、旗帜、风车、吊篮和系泊绳使用同向气流提示。
- **光影**：渐层天空、夕阳、分层程序化云团、天空 / 云海补光、软阴影、金色街灯与窗光、远景雾化。三种观察距离兼顾完整轮廓与建筑、皮肤细节。

飞行是艺术化的浮力与阻尼近似；云层使用程序化透明精灵，非流体求解或科学级体积云。鲸背之城的意象启发于《精灵世纪》，未使用其封面、角色模型或贴图，几何造型与城镇均由代码原创生成。
