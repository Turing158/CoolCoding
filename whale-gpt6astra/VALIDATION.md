# 云鲸渡验收记录

日期：2026-09-18。使用 **Codex 内置浏览器**，通过 `http://127.0.0.1:8134/` 实测。静态场景无需 npm 构建，JavaScript 已通过 `node --check`，仓库修改已通过 `git diff --check`。

## 有限帧数与静止

- 测试 URL：`?test=1&fps=6&frames=12`，浏览器像素比为 1。
- 内置浏览器报告 `prefers-reduced-motion: reduce`，页面首先只绘制 1 帧并暂停。主动点击继续后，每批恰好绘制 12 个动画帧，自动暂停并停止调度。
- 第一批：时间从 4.2 到 6.2 秒，尾鳍高度从约 1.178 到 -0.160，风车角度从 -1.512 到 -2.232。
- 第二批：初始时间 19.8 秒，12 帧后时间为 21.8 秒；`animationFrames=12`、`totalFrames=13`、`paused=true`、`stoppedByBudget=true`、`scheduled=false`。
- 停止后仅视角、光照、尺寸等主动操作触发有限重绘。未做持续 24/30/60 FPS 压力测试，也未用低帧数结果推断所有设备的持续性能。

## 文件与边界

- 主交付为 `index.html`，约 750 KB，已内嵌 Three.js r160 与 MIT 许可；运行时几何、贴图、云雾均程序化生成。`README.md` 与 `PROMPT.md` 为附带说明，不是运行依赖。
- 浏览器工具的 URL 安全策略禁止访问 `file://`。因此未在内置浏览器中完成文件协议的直接打开测试；已在本地 HTTP 下验证无外部资源，并检查单文件脚本结构，不绕过浏览器限制。
- 手机和平板使用浏览器视口模拟，未使用真实触屏设备；右键平移与双指手势已实现，但没有在本次工具交互中完成实体设备验证。
- 飞行、云层绕流和阻尼为艺术性近似。云层是程序化透明精灵，非科学级流体或体积云。
- 已同步根目录总览与规范指定的项目介绍文档，介绍文档顶部信息区逐字保留；验证哈希保存在本地记录中。
