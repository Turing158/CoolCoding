# 原始提示词

使用 Three.js 生成一座充满巧思的、完全来自你想象的城市小镇，它坐落在一头真实感十足、翱翔于天空的鲸鱼背上，风格参照动画《精灵世纪》封面图中鲸鱼城的意象。

要求：

鲸鱼具备真实体量感与生物细节，涵盖皮肤纹理、鳍、尾部、呼吸孔及整体轮廓。

城市小镇需包含富有创意的建筑、街道、灯光与生活气息，体现独特的想象力。

加入明显的 3D 动态效果，例如鲸鱼缓慢飞行、尾部摆动、云层流动、城市灯火闪烁等。

尤其注重物理细节：鲸鱼飞行时的浮力与气流表现、云层与鲸鱼的交互、水面或天空环境对光影的影响，以及物体运动符合力学直觉。

整体场景需有清晰的空间层次与氛围，兼顾宏大视角与近景细节。

最终交付为单个 HTML 文件，可直接运行。
