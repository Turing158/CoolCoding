# 雨夜便利店街角 · 微缩三维场景模型

一个用 Three.js 手工搭建的**三渲二（Cel-shading / 3D-to-2D）**雨夜街角小品：
正方体底座上的日式便利店街角，第三视角自由拖拽 / 旋转 / 缩放观看，
像一件可以收在架子上的微缩模型。

场景内部**没有任何 UI 元素**；所有可调参数集中在画面左上角一个可折叠的设置条里。

## 运行

```sh
npm install
npm run dev        # 开发服务器（默认 http://127.0.0.1:5187）
npm run build      # 生产构建到 dist/
npm run preview    # 本地预览构建产物（默认 http://127.0.0.1:4173）
```

## 操作

| 操作 | 效果 |
| --- | --- |
| 左键拖拽 | 环绕旋转 |

## 场景内容

**底座与街道**：完整正方形底座，L 形车行道 + 抬高的人行道台面，路缘石、
排水沟铁篦、斑马线、停止线、车道虚线、停车位、井盖、盲道黄线。

**便利店（视觉中心）**：绿白斜纹雨棚、门头灯箱招牌（正 / 侧三面）、
青霓虹描边、整面落地玻璃幕墙、可开合的自动门（含门顶感应器）、
门口地垫、店招投光灯。

**店内陈设**（透过玻璃可清楚看到，暖色明亮）：
两组中央货架（四层商品 + 红色价签条）、靠墙五层饮料柜（发光内胆 + 三扇玻璃门）、
便当冷藏柜、冰淇淋 / 冷冻柜、L 形收银台（收银机 + 咖啡机 + 咖啡杯架）、
香烟柜、关东煮柜台（发光汤格 + 吊挂灯箱）、杂志架、后场门与储物柜、
后墙 / 侧墙海报、天花日光灯、地面导视带、店内垃圾桶。

**街角元素**：自动贩卖机、两辆自行车、雨伞架（插着雨伞）、垃圾桶 ×2、
路灯、电线杆与悬链线电线、交通信号灯（含行人灯与路牌）、街角护栏、
空调外机（地面 + 壁挂）、公告栏 / 海报栏、盆栽、小巷入口（下沉通道 + 壁灯 + 管线 + 后门 + 杂物）。

## 动效

- **持续降雨**：GPU 顶点动画的雨丝，带风向偏移与地面淡出
- **屋檐滴水**：雨棚 / 屋顶前缘的间歇水滴
- **地面积水波纹**：实例化扩散光环，贴着真实铺装表面
- **雨水沿玻璃滑落**：滚动贴图的流痕 + 静止水珠
- **招牌 / 灯箱轻微闪烁**：多频正弦叠加 + 偶发瞬时闪断
- **自动门偶尔开合**：随机间隔的减速开合
- **路面积水灯光倒影**：加法混合光带，带呼吸式强弱变化
- **交通信号灯循环变化**：绿 → 黄 → 红，行人灯与倒影颜色同步

## 三渲二做法

- `MeshToonMaterial` + 4 级 `gradientMap`（`DataTexture` + `NearestFilter`）→ 明确的明暗色阶
- **描边**：倒置外壳（BackSide + `depthWrite: false`），沿焊接后的平均法线外扩
- **发光部分**（灯箱 / 灯管 / 灯珠）用 `MeshBasicMaterial`，其余灯箱 / 海报改用带自发光的卡通材质，
  以保留明暗层次而不是糊成死白
- **发光光晕**用加法混合的 `Sprite`，避免引入昂贵的 Bloom 后处理

## 性能设计

- 所有静态部件按材质**合并几何体**（`makeBank` → `mergeGeometries`），
  整个场景约 27 万顶点、~200 个 draw call
- 只有月光一个光源投射阴影；其余为无阴影点光
- 雨 / 波纹 / 滴水全部是 GPU 顶点动画，CPU 每帧不做逐粒子更新
- **帧率上限**默认 40 FPS，避免占满 CPU；实测限帧精确（见下）

## 设置条参数

| 分组 | 参数 | 说明 |
| --- | --- | --- |
| 性能 | 帧率上限 | 10–144 FPS，或关闭限制 |
| 画质 | 阴影质量 | 关 / 低(512) / 中(1024) / 高(2048) |
| 画质 | 渲染倍率 | 50%–150%（配合 devicePixelRatio） |
| 画质 | 轮廓线 | 关掉可检查纯色块渲染 |
| 画质 | 地面积水反射 | 路面灯光倒影 + 水洼高光 |
| 画质 | 湿润高光 | 玻璃清漆、路面粗糙度、倒影强度 |
| 雨与动态 | 雨量 | 0%–150%（实际改变雨点数量） |
| 雨与动态 | 地面积水波纹 / 自动门开合 / 招牌灯箱闪烁 | 各自开关 |
| 视角 | 四个预设视角 / 恢复默认 / 自动旋转 | 带缓动过渡 |

## 验证

`tools/` 下有三个零依赖的 Node 脚本（Node 22+，用内置 WebSocket 走 CDP）：

```sh
npm run dev                                    # 或 npm run preview
node tools/cdp.mjs                             # 交互 + 性能回归测试
node tools/capture.mjs                         # 批量截图（TARGETS 用 ; 分隔）
node tools/diag.mjs "http://127.0.0.1:5187/?test=1"
```

`tools/cdp.mjs` 的实测结论：

| 帧率上限 | 实测渲染帧率 |
| --- | --- |
| 10 | 10.0 |
| 20 | 20.0 |
| 40 | 40.2 |
| 不限 | 143.9 |

- **动效速度**：在 20 / 40 / 不限帧下，模拟时间与墙钟时间之比均为 `1.00`
  （限帧不会让动画慢放）
- **场景**：269 个对象 / 192 网格 / 12 光源 / ~2.2 万三角面 / ~200 draw call
- **交互**：拖拽旋转、滚轮缩放、窗口 resize 均实测生效
- **开关**：轮廓线 39 个外壳全部隐藏 / 恢复；雨量 2800 → 0 → 2800；
  阴影贴图 1024 → 2048；湿润高光改变清漆 1→0.15、路面粗糙度 0.42→0.95
- 控制台**无错误**

## 目录结构

```
index.html          入口（含早期错误捕获，便于无头诊断）
src/
  main.js           渲染器 / 相机 / 主循环（限帧 + 固定步长模拟）/ 设置联动
  kit.js            三渲二工具箱：卡通材质、描边、画布贴图、几何体合并
  environment.js    夜空、灯光、降雨、波纹、滴水、玻璃流痕、路面倒影
  store.js          便利店：建筑外壳 + 玻璃幕墙 + 完整店内陈设 + 自动门
  street.js         底座、路面、人行道、小巷、邻栋、全部街角道具
  effects.js        所有动效的统一调度与开关
  ui.js             可折叠设置条
  style.css         设置条样式（场景内无 UI）
tools/
  cdp.mjs           CDP 交互 + 性能回归测试
  capture.mjs       无头批量截图
  diag.mjs / probe.mjs  诊断辅助
```

## 说明

- 场景中的日文招牌、海报、商品贴图均由 `kit.js` 在运行时用 Canvas 2D 程序化绘制，
  不依赖任何外部图片资源
- 所有随机细节（商品排列、雨点分布、波纹位置）都使用固定种子的 xorshift 随机数，
  每次加载完全一致，便于对比截图
