## 项目介绍

### `building-glm53f` · 体素建筑工地沙盘

一套摆在深色实木工作桌上的微缩工地，包含基坑、钢筋加工棚、物料堆放区、在建楼房、临时板房和施工道路，桌边搭配蓝图、卷尺与安全帽。挖掘机挖土、渣土车接土运输和卸料、塔吊提升与回转共同组成持续运转的施工场景；工人分布在各功能区。

支持左键旋转、右键平移、滚轮缩放和 `R` 键复位，地址栏添加 `?fps=30` 可限制帧率。场景采用合并几何与实例化渲染，几何体和贴图由代码生成；入口为单个 HTML，但 Three.js r160 通过多个 CDN 依次尝试加载，观看时需要网络。

### `building-gpt6astra` · 筑间

“一方工地，一个小世界”：同样以桌面上的体素工地为载体，通过区域导览、标注和解说展示基坑开挖、塔吊吊运与板房办公等工作。渣土车按装载、运输、卸料的时序循环，塔吊先提升再回转，各区域组成可近看细节的施工沙盘。

支持旋转、平移、缩放、分区聚焦、暂停施工、纯净观看、全屏与保存画面，并可调整帧率上限。Three.js r160 与场景代码全部内嵌，`index.html` 可双击离线打开；切换到后台时休眠，暂停后按需绘制。开发时修改 `.build/` 下的源文件，再运行 `node .build/build.cjs` 更新单文件。

### `shop-rainning-glm53f` · 雨夜便利店街角

一座没有界面控件的三渲二便利店沙盘：22×22 的正方形底座收纳 L 形街道、玻璃店面、自动贩卖机、自行车、路灯与邻楼，街角还有一只猫。透过玻璃可见货架、饮料柜、便当柜、收银台、关东煮与 ATM，约 900 个商品实例让室内保持充实。

持续降雨、屋檐滴水、玻璃水痕、积水涟漪、灯箱闪烁和周期性自动门营造雨夜氛围。支持左键旋转、右键平移和滚轮缩放；默认上限 30 FPS，可通过 `?fps=24` 或 `?fps=60` 调整。Three.js r160 保存在本地 `libs/`，需要通过 HTTP 服务打开，详见 [运行与交互说明](shop-rainning-glm53f/README.md)。

### `shop-rainning-gpt6astra` · 雨宿り AMAYORI

一座以暖色店内灯光衬托冷色雨夜的日式街角，包含双面玻璃便利店、四组货架、三组饮料冷柜、408 件商品、便当与饭团陈列，以及完整街道设施。招牌、商品和海报贴图由 Canvas 绘制，雨线与波纹由 GPU 驱动，积水倒影、玻璃水痕和自动门提供细微动态。

底部设置条可以收起，提供节能／平衡／精细预设、6–60 FPS 上限、渲染精度、阴影、反射、雨量、亮度与辉光控制。支持鼠标、触屏和键盘观看，双击或 `Home` 复位；默认上限 24 FPS，后台暂停，画质偏好保存在浏览器中。项目采用 Vite + npm，启动、构建及有限帧数测试方式见 [项目说明](shop-rainning-gpt6astra/README.md)。

### `shop-rainning-opus5` · 雨夜便利店

一个使用 Three.js r160 与 OrbitControls 的单文件雨夜街角，围绕正方形底座搭建便利店、店内货架、街道设施、照明和雨景。降雨、积水波纹、路面灯光反射与自动门开合共同呈现潮湿夜色。

右下角齿轮按钮打开设置面板，可调整帧率上限、雨滴密度、速度与大小，以及阴影质量和抗锯齿，并支持重置默认设置。可拖动旋转、滚轮缩放和右键平移；Three.js 与 OrbitControls 通过 CDN 加载，需要联网，建议使用本地 HTTP 服务访问。

### `shop-rainning-ds41f` · 雨夜便利店街角

一座采用四级卡通明暗与外壳描边的日式便利店沙盘。正方形底座上有 L 形道路、抬高的人行道、玻璃店面、绿白斜纹雨棚、两辆自行车与下沉小巷；店内布置货架、饮料柜、便当柜、冷冻柜、L 形收银台、咖啡机、关东煮和杂志架。招牌、海报和商品贴图在运行时由 Canvas 绘制。

左上角可折叠设置条提供帧率、阴影、渲染倍率、轮廓线、积水反射、湿润高光、雨量和动效开关；默认上限 40 FPS。支持左键旋转、右键平移、滚轮缩放，`1`–`4` 切换街角、店面、俯视和小巷视角，`H` 收起或展开设置条。雨丝、波纹与滴水使用 GPU 动画，自动门和交通灯持续变化。

项目采用 Vite，Three.js 依赖为 `^0.169.0`。在目录中运行 `npm install`、`npm run dev`，默认打开 `http://127.0.0.1:5187/`；`npm run build` 输出静态文件，`npm run preview` 默认使用 4173 端口。完整参数和运行说明见 [项目 README](shop-rainning-ds41f/README.md)。

### `gardon-gpt6astra` · 湖畔花园的四季来信

这是一个离线单文件 Three.js r160 体素花园：场景摆在窗边的木质桌面上，包含湖泊、小岛、书屋、玻璃温室、咖啡屋、桥、人物和小船。时间会独立推动四季与昼夜，春花、夏叶、秋雾、冬雪和结冰湖面会平滑过渡；小船会在湖面结冰前靠岸，解冻后重新出航。

场景支持左键环视、右键平移、滚轮缩放、俯瞰与纯净观景模式，并提供暂停时间、四季进度、流年速度和天气强度控制。所有几何体、材质、贴图、环境音和动画均由代码生成，验证构建无外部资源请求；默认四季循环约 8 分钟，也可切换节能模式或开启合成环境音。

双击 `index.html` 即可离线观看，无需安装依赖。开发源文件保存在 `.build/`，运行 `node .build/build.cjs` 可重新生成单文件；`node .build/serve.cjs` 在 `http://127.0.0.1:8765/` 提供本地预览。

### `gardon-ds41f` · 湖畔花园的四季来信

一座摆在橡木桌上的四季微缩花园，包含起伏地形、溪流与湖泊、小岛、书屋、玻璃温室、亭子、木桥、码头和小船。植物、花朵、蝴蝶、飞鸟、萤火、落叶、雨雪、薄雾与湖冰分别随季节变化，昼夜光照和日照时长也随时间调整；小船会在湖面冻结前返回泊位。

支持拖动环视、滚轮缩放和自动环绕，可点击季节进度条，或拖动桌上的三枚铜旋钮调节流速、季节与天气。设置面板提供省电／均衡／精细预设、30–120 FPS 或不限帧、渲染比例、阴影、粒子密度、曝光、柔光和闲置暂停选项；默认上限 60 FPS，四季完整循环约 480 秒，可调为 120–900 秒。

Three.js r160 与场景代码内嵌在单个 `index.html` 中，几何体和贴图由代码生成，可双击离线观看；也可通过本地静态 HTTP 服务预览，无需 npm 安装或构建。

### `lego-gpt6astra` · 层间 STACKED

一座被透明外壳包裹的四层乐高风格小城：底层是有红色小车和维修员的车库，其上依次是棕色街屋与黄色巴士、橙色电车公园，以及停放彩色车辆的屋顶花园。Three.js 严格使用 r160，积木、门窗、小人表情、轨道、花坛与标牌都由代码生成，构建后不依赖外部素材或 CDN。

支持楼层近景、左键旋转、右键平移、滚轮细节缩放、楼层展开与 PNG 留影，面板可调画质、6–60 FPS、透明度、花粉和阴影。约 6,721 个部件采用实例化渲染，24 个角色／车辆受边界与碰撞约束；粒子复用固定对象池。已使用 Codex 内置浏览器进行有限帧数实测，并提供 `?test=1&fps=6&frames=12` 自动暂停模式，避免持续占用 CPU。

在 `lego-gpt6astra/` 运行 `npm install`、`npm run dev`，打开 `http://127.0.0.1:8130/`；`npm run build` 生成静态部署文件，`npm run check:motion` 无需渲染即可检查完整运动路径。需通过 HTTP 服务访问，完整控制和运行方式见 [项目说明](lego-gpt6astra/README.md)。

### `beijing-temple-of-heaven-gpt6astra` · 天坛，天地之间

一座可以走近、环绕与逐层拆解的祈年殿。三重微翘曲面蓝瓦屋顶、鎏金宝顶、28 根朱柱、彩绘斗拱、隔扇门窗和三层汉白玉圆坛均由 Three.js r160 在运行时生成；瓦垄、石栏、斗拱等共 7,098 个构件实例化，不加载外部模型、图片、字体或 CDN。

支持拖动旋转、滚轮缩放、右键平移、三种预设视角与可开关的缓慢自动环绕。屋顶、柱、斗拱、墙、门窗、栏杆和台基按节奏展开并精确重组；平衡画质使用软阴影、SSAO 与电影色调映射，静止和后台停止绘制。`?test=1&fps=6&frames=12` 提供有限帧数实测模式。

在 `beijing-temple-of-heaven-gpt6astra/` 运行 `npm install`、`npm run dev`，打开 `http://127.0.0.1:8132/`。`npm run build` 生成部署文件，`npm run check` 无需 WebGL 即可检查曲面、实例矩阵及 12 次拆解／重组。模型为艺术性建筑重现，非测绘级复原；详见项目的 [启动说明](beijing-temple-of-heaven-gpt6astra/README.md) 与 [验收记录](beijing-temple-of-heaven-gpt6astra/VALIDATION.md)。

### `whale-gpt6astra` · 云鲸渡 WHALEHAVEN

一座在巨鲸背上穿过暮色云海的小镇，交付为可双击离线运行的单个 `index.html`。Three.js r160、斑驳皮肤、腹褶、鳍与尾部、双呼吸孔、22 栋街屋、铜绿天文台、钟楼、风车、栈桥、灯串和系留热气球均内嵌或程序化生成，无外部素材请求。

鲸身缓慢升沉，尾柄连续弯曲、尾鳍延迟摆动，云气绕行并形成尾后扰动；旗帜、烟雾和吊篮随风运动，13 位居民沿栈桥的闭合路线漫步。支持全景、小镇与鲸鱼近景，拖动旋转、滚轮缩放、右键平移、昼夜天光、暂停、纯净观景与 PNG 留影。默认上限 24 FPS，节能模式 12 FPS，暂停和后台停止渲染；Codex 内置浏览器使用 `?test=1&fps=6&frames=12` 有限帧数验证。意象启发于《精灵世纪》，造型与城镇为原创程序化设计。

无需 npm 安装或构建，双击 `index.html` 即可离线观看。快捷键、诊断参数与实现说明见 [项目 README](whale-gpt6astra/README.md)，具体验收记录见 [VALIDATION.md](whale-gpt6astra/VALIDATION.md)。

### `shop-rainning`

```text
请制作一个雨夜便利店街角小场景，以第三视角观察整个场景，整体像一个可以自由拖拽、旋转、缩放观看的微缩三维模型 / 小型景观，没有任何UI界面元素。地面为一个完整的正方形底座，所有元素都搭建在这个底座上，构图紧凑、层次清晰，整体呈现出小巧、精致、可收藏的模型感。画面风格为三渲二，强调浓厚的日式二次元动画氛围，材质表现干净，轮廓明确，色彩柔和但富有夜景霓虹的层次感。
```
